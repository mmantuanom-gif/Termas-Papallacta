## Descripción del Proyecto
**Termas & Rutas Papallacta** es una plataforma web institucional desarrollada para una agencia tour-operadora especializada en promocionar el turismo de salud termomedicinal, el ecoturismo de alta montaña y la gastronomía andina en la parroquia Papallacta, cantón Quijos, Provincia de Napo.

El portal implementa una arquitectura multipágina de 5 vistas enlazadas con navegación semántica:
1. **Inicio (`index.html`):** Portada principal con banner asimétrico, panel Glassmorphism de datos climáticos, atractivos destacados y llamados a la acción.
2. **Lugares Turísticos (`destinos.html`):** Catálogo formal con 6 atractivos oficiales provistos de datos de altitud, temperatura y actividades turísticas recomendadas.
3. **Servicios (`servicios.html`):** Tarifario con 4 paquetes de servicios categorizados, detalles de inclusiones y precios transparentes por persona.
4. **Nosotros (`nosotros.html`):** Historia de la agencia, pilares corporativos (misión, visión y valores) y cuatro razones de valor para visitar el valle termal.
5. **Contacto (`contacto.html`):** Canales directos de atención y formulario semántico puro en HTML5 con validaciones nativas de campos.

---

## Tecnologías Utilizadas
* **HTML5:** Estructuración y marcado semántico nativo (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<form>`).
* **CSS3:** Hoja de estilos externa modular utilizando Variables CSS, Box Model, diseño responsivo mediante CSS Flexbox, CSS Grid y Media Queries sin frameworks ni librerías adicionales.
* **Git & GitHub:** Sistema de control de versiones y repositorio público en la rama principal (`main`).
* **GitHub Pages:** Despliegue estático y alojamiento web público en la nube bajo protocolo HTTPS seguro.
